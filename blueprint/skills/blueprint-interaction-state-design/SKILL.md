# 交互状态与布局验证；在对应验证或交付场景下使用。

从用户动作列出控件的静止、悬停、按压、键盘焦点、禁用、忙碌与错误反馈，避免反馈与状态含义冲突。
检查窄桌面、常用窗口、宽屏和长文案，确保主要操作不被截断、弹层不遮挡当前任务。动效说明进入、离开或状态变化，并支持快速反向操作。

执行前调用平台提供的 ensure_role_environment，核对本节点真实执行环境。缺项先准备并复核；安装失败或能力不兼容应返回具体证据，不把注册视为已加载。遵守平台工作区、权限和交付协议。
